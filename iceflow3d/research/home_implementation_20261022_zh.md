# HOME 动量 + D3Q7 原地相场：实现、浮力与 FP32 审查

日期：2026-10-22。对象：当前 `iceflow3d` 三维生产求解器。迁移前提交：`7889ec4fea33cefca4404559e81a5d54f30b1d63`。二维求解器和此前运行使用的冻结源码保持独立。

本页保留最初 HOME 迁移版本的验证记录。后续参照 `Home_ThreePhase` 修正了三阶 `xyz` 重建项系数（13.5 → 27），并优化了并行路径；当前源码及性能验收请看 [README](../README.md) 和 [优化记录](../outputs/home_optimization_450_20261022/)。本页旧验证数字不自动代表后续版本。

已实现 D3Q27 HOME 动量、D3Q7 AA 原地相场，两者均采用中心矩 MRT。生产 GPU 路径全部使用 FP32；本轮验证没有发现必须保留 FP64 的生产 GPU 位置。CPU 的姿态/接触解算和诊断仍使用双精度。**这不是把旧分布函数无损压缩：动力学闭合已经改成 HOME。**

## 高密度比耦合与浮力

HOME 存储速度型矩，`p*=3p_dynamic/rho`。一阶矩不再是原来的密度加权动量，所以不能沿用旧力项后直接除以新密度。

本次进行了以下同步修改：

1. 相场质量通量对速度的修正由 `-div(Ju)` 改为 `-div(Ju)+u div(J)`，共享面使用同一个质量通量和上风速度。均匀速度在相场扩散时保持不变；原有面速度跳跃耗散仍保留，并有独立守恒/功率预算测试。
2. 归一化压力的修正加速度写为 `grad_h(p/rho)-grad_h(p)/rho`，与 `p*=p/(rho cs²)` 的单位一致，避免在密度比 800 的界面直接使用点乘积近似造成额外压力梯度误差。
3. 保留 `nu (grad u + grad u^T) grad rho / rho` 这一变密度黏性力。这里计算速度导数是为了该力项；碰撞的剪切应力始终来自中心矩，没有用有限差分应力替换，没有 HRR。
4. 运动冰面上的分布交换先乘回局部密度，再计算流固冲量和力矩。参考静水压力仍单独加入冰面受力；流体中的参考压力/重力相消不能导致冰失去浮力，也不能重复加一次阿基米德力。
5. 相场 AA 的奇偶状态进入检查点。冰运动或融化改变流固标签时，只交换发生变化的链接地址，再补充新暴露格点。已有流体的逻辑分布保持原值。初始相场松弛期间不提前施加尚未移动冰面的速度。

边界依旧使用原切割链接插值、局部镜像和几何阈值。没有靠改密度、增黏或加速度限幅让浮力测试通过。

环境：RTX 3090、Taichi 1.7.4、CUDA。GPU 上另有用户原运行，因此这里不把墙钟时间当作独占设备的性能对照。

| --- | --- |
| CUDA 回归 | 48/48 通过 |
| CPU 核心回归 | 5/5 通过 |
| HOME 重建/碰撞 | 128 组随机状态，对照独立矩求和及中心矩推导；包含非零力和不同剪切/体积松弛率 |
| D3Q7 碰撞 | 256 组随机状态，对照完整 7×7 中心矩矩阵求逆 |
| 相场原地寻址 | 两个奇偶步连续推进，与独立双缓冲 push 参考比较；覆盖静止容器、运动冰面与流固标签变化 |

拟合界面宽度与参数 W 的小差别来自空间离散及法向正则化；程序中的 W 始终为 5。没有为了使拟合值等于 5 而调整 W。保留的默认法向正则化 0.01 仍会留下约 0.006 的体相混合分数；本次没有用更小正则化的测试结果替代默认配置验收。黏度验证同时覆盖纯相和均匀混合物。

### 浮力专项

固定 8³ 格冰块，在均匀纯水、空气和水相分数 0.37 的流体中，以排开流体重量为独立参考。

| 工况 | 浮力/加速度相对误差 |
| --- | ---: |
| 纯水静水浮力 | 约 0.00123% |
| 空气静水浮力 | 约 0.00069% |
| 混合密度静水浮力 | 约 0.00097% |
| 加上冰自身重力后的净加速度 | 约 0.0154% |
| 水温增加 10 K 后的 Boussinesq 热浮力 | 约 0.0000383% |
| W=5 弥散自由液面、部分浸没冰块 | **0.539%** |

部分浸没测试按连续 tanh 密度剖面在冰体内积分，选取应与冰重平衡的水面高度。它的约 0.54% 偏差包含固定 W=5 下链接压力插值和空间离散误差。保持该密度剖面，推进动量 256 步后，最大静水 L1 速度约 `1.64e-12 LU`。这是静水/受力验证，不是声称已完成任意形状运动冰体的网格收敛验证。

证据：[浮力](home_validation_20261022/buoyancy.json)、[黏度](home_validation_20261022/molecular_viscosity.json)、[界面](home_validation_20261022/planar_phase.json)、[CUDA 回归日志](home_validation_20261022/cuda_regression_tests.log)、[CPU 核心日志](home_validation_20261022/cpu_core_tests.log)、[运动冰面与模型配置补充检查](home_validation_20261022/moving_phase_and_config_tests.log)、[细网格耦合](home_validation_20261022/coupled_450_256.json)。

### FP64 参考对照

在独立临时源码副本中，把**本次由 FP64 转换的热模块及刚体受力/质量/惯量归约**恢复为 FP64，其余物理参数相同。两组各运行 2,000 步（0.05 s），流动/相场均为 FP32；HOME 流动本身另外与 NumPy FP64 线性特征模态比较。这里不把该对照称为“全部模块均为 FP64”。

| FP32 对 FP64 参考 | 差异 |
| --- | ---: |
| 水相分数相对 L2 | `1.37e-7` |
| 速度相对 L2 | `3.66e-6` |
| 最大速度差 | `2.99e-5 m/s` |
| 流体压力相对 L2 / 最大差 | `4.59e-5` / `0.0399 Pa` |
| 最大温差 | `0.00842 °C` |
| 冰质量相对 L2 | `6.37e-8` |
| 固体格点分类 | 一致 |

压力比较使用两组共同的流体格点；固体内部保存的旧动态压力不是流体压力解，原始全域差异也保留在 JSON 中。证据：[对照汇总](home_validation_20261022/precision_comparison.json)、[FP32 字段清单与诊断](home_validation_20261022/precision_fp32.json)、[FP64 参考记录](home_validation_20261022/precision_fp64_reference.json)。复现工具：[audit_gpu_precision.py](../benchmarks/audit_gpu_precision.py)。

FP32 热状态不能满足原 FP64 状态的 `1e-11 J` 绝对逐步舍入容差。一次短换热对照中，接收热量约 `1.2978e-4 J`，储能舍入造成约 `1.59e-7 J` 差异。测试现在用**参与换热格点的半 ULP 储能预算**检查这部分误差，仍独立检查等量反向通量、热输运、融化和温度。没有修改稳定性保护或物理系数来放过测试。上述 FP64 耦合对照进一步限制了累计温度、质量和速度误差。

**稳定运行不等于长期守恒精度已经达标。** 既有模型中冰融化后消失，不向液相添加等质量的水；因此不能把这项 +1.285% 的水量变化简单扣除融化量后宣称守恒。它是当前完整耦合下需要进一步定位的误差，尚未归因于 HOME、移动几何、相场离散或 FP32 中的某一项。本次没有开启全局投影掩盖它，也没有改变 W、黏度或 dt。静态浮力专项和短时 FP64 对照通过，并不消除这一长期误差。

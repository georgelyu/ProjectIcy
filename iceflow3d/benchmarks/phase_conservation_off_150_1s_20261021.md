# 关闭全局水相守恒修正：150×50×30、1 s 验证

2026-10-21。已按要求注释全局水量守恒修正，但**当前默认 CM-MRT 未通过从初始条件开始的 1 s 验证**。开启原有投影的 CM-MRT 对照在同一步、同一位置失败；CM-HRR 对照在关闭投影时完成 1 s。默认碰撞仍为 `cm_mrt`。

## 修改范围

在 `simulator.py` 中注释以下三个完整实现及 `_refresh_geometry` 中的调用：

- `_measure_phase_balance`：全域水相总量/界面容量归约。
- `_project_phase_volume`：界面重分配，及其对 h/f 分布、动量的补偿和记账。
- `_conserve_phase_volume`：误差判断、投影迭代及收敛检查。

Python 配置和 CLI 的 `conserve_phase_volume` 默认值均为 `False`。配置字段和零值诊断字段保留；求解器拒绝显式启用已注释的功能，避免记录配置与实际执行不一致。profiler 中对应的三个方法条目也已注释。

本次“关闭守恒”指上一轮讨论的额外全局总量约束。相场碰撞的局部零阶矩闭合、相场限幅、水热场同步、相场质量通量与动量耦合继续执行；逐步稳定性、热子步和接触检查均有效。

AST 对比确认，除上述三个方法移除、构造函数的失效选项检查及几何刷新调用外，其余求解器方法未变。碰撞、迁移、补点、热输运和刚体核没有进行稳定化修改。

## 从零开始的三组对照

共同设置：CUDA / RTX 3090；150×50×30；格距 1 mm；`dt=25 μs`，目标 **40,000 步 / 1 s**。保留 2000 步相场预热、5 格界面、四块活动冰、热对流与融化；每 8 步更新导热/融化。气相异常修复关闭，速度保护上限维持 L1 速度 0.5 LU。

| 碰撞模型 | 全局水量投影 | 结果 | 累计最大 L1 速度 | 末态/失败态相量漂移 |
| --- | --- | --- | ---: | ---: |
| **CM-MRT，当前默认** | **关闭** | **第 1382 步失败，约 0.03455 s** | **0.527345 LU** | **−0.039715%** |
| CM-MRT，冻结旧源码对照 | 开启 | 第 1382 步失败，约 0.03455 s | 0.529517 LU | −0.000520% |
| CM-HRR，对照 | 关闭 | **完成 40,000 步 / 1 s** | **0.208362 LU** | **+1.587980%** |

两组 MRT 的配置差异只有 `conserve_phase_volume`；关闭投影的 MRT/HRR 两组差异只有碰撞模型。开启投影的对照使用单独冻结的修改前源码，工作树中的注释保持不变。

MRT 两组都在格点 **(1, 1, 25)** 触发保护，靠近水槽左端底部，冰覆盖率为零。关闭投影时该格点 `phi=0.902996`，速度约 `(-0.187105, -0.188419, 0.151821)` LU，属于水相占优区域。

失败发生在流体更新后的稳定性扫描处，尚未执行本步几何刷新。最后完整完成的步数为 **1381 / 0.034525 s**；`failure.npz` 保存第 1382 步的部分更新状态。因此，开启投影对照的失败态水量误差也包含本步尚未校正的误差，不能据此判定其投影失效。

这些对照说明：**当前 CM-MRT 的早期失稳并非停用全局水量投影后才出现。** 本次定位到碰撞模型相关的差异，尚未确定 CM-MRT 与边界/两相耦合的具体失稳根因。没有通过切换默认模型、放宽速度上限或缩短目标时间来宣称默认配置验收通过。

## HRR 对照的 1 s 核验

使用带显式 `--without-phase-conservation` 标记的核验入口；水量漂移作为结果报告，原有有限性、能量记账、速度、温度和接触检查保持有效。

- 41 个采样时刻覆盖 0–1 s；逐步累计最大速度 **0.208362 LU < 0.5 LU**。
- 保存的全部场有限，相场在 [0,1]，温度在 **[0,90] °C**。
- 所有采样的相量投影和投影动量补偿为零；气相修复和待补点数量为零。
- 液水体积约 **103.598 → 105.243 mL**，增加 **1.645 mL / 1.588%**。
- 计入显式热重映射记账后的最大能量残差 **1.285×10⁻⁶ J**；末态热重映射累计 **593.395 J**，该记账项没有被忽略。
- 四块活动冰均在容器内；末态接触穿透和闭合速度残差为零。
- 运行墙钟 **210.10 s**，包含初始化、JIT、诊断和文件输出，不是纯 step 性能数据。

核验通过仅表示此 HRR 对照完成了指定的短时运行与检查，不表示保持水量守恒，也不表示默认 CM-MRT 通过。

## 回归与复现

CUDA 完整测试集 **29 项通过**；配置/刚体/输出测试 **16 项通过**。补点测试已改为检查无全局投影时的供体相量保持、原有流体不被全局调整，以及补点带来的总体积变化。修改的 Python 文件通过 Ruff 和语法检查。

当前工作树复现失败的默认模型测试：

```bash
python iceflow3d/benchmarks/diagnose_stability.py \
  --resolution-x 150 --end-time-s 1 \
  --momentum-collision-model cm_mrt --no-conserve-phase-volume \
  --sample-steps 1000 --snapshot-interval-s 0.1 --checkpoint-interval-s 0.5 \
  --no-plot --output-dir iceflow3d/outputs/repeat_phase_off_mrt_1s
```

将模型改为 `cm_hrr` 并选择新输出目录可复现成功的对照。完成后核验：

```bash
python iceflow3d/benchmarks/verify_stability_run.py \
  iceflow3d/outputs/repeat_phase_off_hrr_1s \
  --end-time-s 1 --resolution-x 150 --without-phase-conservation
```

原始证据位于 `outputs/phase_conservation_off_150_1s_20261021/`：

- `run/`：当前默认 MRT 失败记录、原始失败场。
- `control_mrt_projection_on/`：开启投影的 MRT 失败对照。
- `control_hrr_projection_off/`：1 s HRR 对照、11 帧原始场、末态、两份完整检查点及 `verification.json`。
- `source/`、`control_source/`：本轮两版冻结源码；`before/`：修改前文件。
- `tests_cuda.log`、`tests_config_rigid.log`：回归日志。

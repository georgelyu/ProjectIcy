lattice.py:13–26, 29–80 同时保留 Python 常量和 Taichi 分支函数。review 时要确认二者完全一致；测试只直接使用 Python 的 C/W。

fqeq(ρ,u) = wqρ[1 + 3(cq·u) + 4.5(cq·u)² − 1.5(u·u)]
hqeq(φ,u) = wqφ[1 + 3(cq·u) + 4.5(cq·u)² − 1.5(u·u)]

两式仅把标量从 ρ 换成 φ。本求解器实际调用 _feq(q,1,u)，所以 f 是单位参考密度的速度/压力分布，物理混合密度单独存在 rho 场中。lattice.py:83–97

两种“平衡态”要分开核：初始化、refill 和部分墙面处理调用上述二阶 _feq/_heq；正式 collision 则直接指定中心矩，包含张量积高阶平衡矩。它们到二阶速度一致，但一般在 O(u³/u⁴) 不同，因此重建节点进入下一次碰撞时存在一次模型切换。建议用 moments/property test 明确可接受误差。

拓扑与坐标约定

  • 场索引是 [i,j,q] = [x,y,direction]；单元几何中心是 (i+0.5,j+0.5)。simulator.py:170–204, 676–678
  • active(i,j) ⇔ wall==0 ∧ solid==0；wall 是静态容器，solid 是当前刚体中心点光栅。simulator.py:546–548
  • φ=1 表示水，φ=0 表示空气；混合属性先 clamp 到 [0,1]。lattice.py:104–119
  • 刚体几何用世界坐标（格子 cell 单位），角度为弧度；局部点通过 R(−θ)(x−center) 进入 box frame。
  • solid_fraction 是 cell 面积占比但只用于审计账本；LBM 控制体仍由二值 active 决定。

初始几何公式

q = |R(−θ)(x−xc)| − (w/2,h/2)
SDF(x) = ‖max(q,0)‖₂ + min(max(qx,qy),0)

cell center 的 SDF≤0 才标为 solid。相切 cell center 会被算作 solid；fractional geometry 则用真实单元方形与旋转矩形相交，不依赖这个二值判定。

8. 守恒相场 LBM

第二套 D2Q9 populations h 追踪水相体积分数。代码对应保守 Allen–Cahn 型界面方程，而不是自由表面 VOF，也不是 Cahn–Hilliard 四阶方程。

目标连续方程（由 collision/source 形式还原）

∂tφ + ∇·(φu) = ∇·{ M[∇φ − (4φ(1−φ)/W)n] },   n=∇φ/(|∇φ|+10−14)

代码推导 4φ(1−φ)/W 是把界面维持在 logistic/tanh 平衡轮廓的压缩通量；τφ=0.5+3M，实现中使用其倒数。simulator.py:1131–1151

  1. 用与流体力相同的混合 stencil 求 ∇φ、法向和 compression。
  2. 对当前 h、平衡 heq(φ,u_temp)、以及 Fqφ=wq·compression·(cq·n) 分别计算九个中心矩。
  3. 一阶矩用 BGK 型 k′=k−τφ⁻¹(k−keq)+(1−0.5τφ⁻¹)kF；其余矩直接设为 keq+0.5kF。

τφ−1 = 1/(3M+0.5),   Fqφ=wq[4φ(1−φ)/W](cq·n)

9. 尖锐移动边界、streaming 与动量交换

9.1 Cut-link 交点

从 active cell x 沿 cq 推向 solid cell 时，用两端 SDF 做线性零点插值：

η = clamp(SDF(x) / [SDF(x)−SDF(x+cq)+10−12], 0.05, 0.95)

clamp 防止退化插值，但也把非常靠近节点的真实界面强制移到链路的 5%–95%。simulator.py:1269–1283

9.2 速度 population 反弹

默认 rigid_boundary_scheme="unified"。若后方 cell x−cq active：

若 scheme 选 halfway，或 unified 所需后方 cell 不 active，则：

9.3 Galilean-invariant link momentum exchange

Δplink=ρ(φ){(cq−ub)fout−(−cq−ub)fref−2wqcq}
Jhydro,raw=ΣΔplink,   Lhydro,raw=Σ(rb×Δplink)

乘 ρ(φ) 发生在动量交换，而不是 moving-wall population correction；这与 f 的单位密度约定一致。额外的 −2wq cq 是代码中的静态基线扣除项，需要从采用的 GME 公式和符号约定独立推导。simulator.py:1296–1310

9.4 相场无通量反弹

hbar qnext(x)=hq*(x)−6wqφ(x)cq·ub （移动冰）
hbar qnext(x)=hq*(x) （静态墙）

代码注释的 “Liu et al. Eq. 51” 可定位到 Liu–Ye–Zhang–Zheng (2023) 的相场 LBM–MPM 耦合论文；完整书目信息见第 17 节。当前注释仍应补上完整来源，而且 reviewer 还需直接打开论文 Eq. 51，核对其方向、壁面速度和本代码 push-stream/halfway 约定，而不能只凭同形公式认定复现。simulator.py:1322–1350

代码没有接触角、壁面自由能或润湿参数；纯反弹只能按近似无通量/中性润湿边界理解，不能从当前输入指定其他静态或动态接触角。

两套边界几何并不相同：速度 population 在默认分支使用 SDF 交点 η 的 unified interpolation；相场 population 对同一移动冰面始终使用 halfway 反弹，不读取 η。因此动量边界和相场无通量边界代表的有效壁面位置可能不一致，需要界面贴壁/移动斜面收敛测试。

9.5 静态容器墙

速度分布采用同点反弹；当 opp(q)<q 时才混入 10% 的静止平衡态，否则完全反弹：

fbar qnext = 0.9fq*+0.1fbar qeq(1,0)   if bar(q)<q;   else fq*
方向依赖：阻尼是否施加取决于 q 的编号，而非几何法向或每对方向对称规则。它继承自 mixture2d，但可能产生方向不对称；需要通过静水/反向流/旋转网格测试判断，而不是只看注释。

10.1 显式 Archimedes 浮力

速度型归一化 LBM 没有提供绝对静水压力牵引，代码另做一个体积近似。对每个二值 solid cell，沿同一世界高度求 OBB 水平 chord 两端，在盒外最多各取 3 个 active 样本，再按 cell 在 chord 中的位置插值 φ。simulator.py:1468–1525

把每个二值 cell 权重缩放到解析矩形面积，因此完全浸没时排水面积精确为 w·h。浮力只作用于质心，刻意不产生 torque；它也没有向流体施加等反向体力。simulator.py:1527–1554

底板法向 n=(0,1)、切向 t=(1,0)。四角在旧 pose 下建立 lever arm；若 gap 在 slop 内，或预测一步会穿透，就激活 contact。12 轮顺序冲量：

10.4 位置修正与侧/顶墙

用接触后速度做半隐式 Euler：angle+=ω、center+=V。然后对实际四角再做 12 轮 split impulse 位置修正：80% 超出 1e−5 slop 的穿透按相同广义逆质量同时修正 center.y 和 angle，但不改物理速度。

命名：所有 *_impulse 每个格子步直接加到动量；格子 Δt=1 时数值上与 force 相同，但物理解释应称 impulse。低通滤波的对象也是 impulse，启动时会把第一步水动力缩小到 α 倍。

12.4 受限 Newton–bisection

  1. 若 clip 后误差在 tol·max(1,|Vtarget|) 内，直接返回。
  2. 若没有 mask cell，报 infeasible；不向 bulk 播种。
  3. 先算 V(±λlimit)，目标不在可达区间就报 exceeds permitted shift。
  4. 从 λ=0 开始 Newton；导数无效或 proposal 出 bracket 时改用二分。最多 64 次。
  5. 由于 f32 map 是阶梯函数，保留残差最小的 best λ；只有满足声明 tolerance 才接受。

容差：默认相对 tolerance 1e−9 对大网格 target 会放宽为约 O(10−5) cells；测试 helper 采用另一个更宽的 max(5e−5,5e−8 target) 判据。文档/测试/配置三者的“strict”需要统一解释。

  • save_frame 调 render kernel；Taichi native image 是 (nx,ny,3)，文件先 transpose 为 (ny,nx,3) 再竖直 flip。优先 imageio；任意异常都 fallback 到 matplotlib。simulator.py:334–353
  • NPZ 保存 φ、rho、u、p、solid、solid_fraction、sdf 和四个刚体状态；不保存 f/h populations，因此不能无损 restart。simulator.py:355–371
  • GUI 使用 native layout；每次 gui.show() 与文件保存同一帧，但代码没有处理用户关闭事件。

Metadata 与诊断

metadata.json 包含固定能力声明、Taichi 版本、steps/frame、格子缩放、完整 config 和一次 diagnostics() 快照。diagnostics 把 16 个大场全部传回 NumPy 来检查有限性，并计算 active φ min/max、最大流速、body inside、各种 impulse/volume/GCL 值。simulator.py:373–541

成本与错误语义：写 metadata 会把所有大场从 GPU 拷回 CPU；默认只在 run 前后发生。save_frame 对 imageio 的 所有异常都尝试 matplotlib，可能把权限/磁盘错误误判成“缺少 imageio”。
finite 标志并非全状态证明：fluid_finite 的 16 个数组不含以后会参与 refill 的 stored_phi/stored_pressure，也不含图像等辅助场；rigid_finite 的 scalar 列表不含 water_volume_raw、projection mass/derivative 等若干公开诊断。因而两个标志都为 true 仍不能推出所有保存字段/未来读取状态有限。另有 water_volume_raw==water_volume_current 的重复语义。
可复现性：metadata 没有源码 commit、工作区 dirty 状态、GPU 型号、随机种子（当前无随机）、执行命令或依赖版本（除 Taichi）。本文的 snapshot 信息不由运行代码自动写入。

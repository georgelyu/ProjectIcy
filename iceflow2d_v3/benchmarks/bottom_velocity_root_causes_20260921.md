**CM-MRT 底部两类速度异常：原因、对照试验与方案（2026-09-21）**

本文保留实现前的诊断过程与数据。两项优化现已加入生产代码，参数与后续验证见
[实现验证记录](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/benchmarks/stability_options_validation_20260921.md)。

主要机制已定位：固定斑点及竖向伪流来自纯水区相场污染及其力反馈；快速速度抖动来自压力模型的数值声学驻波。两者耦合，但需要分别处理。仅更换动量碰撞坐标系不能同时消除它们。

本次只在独立诊断副本中修改、运行对照，生产求解器、配置及原输出没有改动。原有 RM-MRT 选项保持原状。

**对照条件与统计口径**

复现用户确认的 CM-MRT 默认算例，100×200，dx=0.25 mm，dt=6.25 μs，密度比 800，90 ℃ 水的运动黏度约 3.142×10⁻⁷ m²/s。所有完整对照恢复同一个初始化后检查点，再从 t=0 运行到 1.07 s。物理黏度、界面宽度 W=5、mobility、平衡态和动量源项表达式均相同。候选声学松弛使用自己的 `(1-s/2)` 源项系数。

为避免把壁面角点误差与内部斑点混在一起，瞬时统计区域为 x∈(2,23) mm、y∈(2,13) mm。压力与速度波动在这个区域每隔 4 格采样，时间窗为 1.0700–1.1212 s，每 8 个 LBM 步采样一次，采样间隔 50 μs；先减去每个采样点的时间均值，再计算 RMS。速度波动 RMS 为二维向量的 RMS。瞬时速度大小不能与这个波动 RMS 混用。

**1. 固定斑点和竖向伪流：相场误差被压缩通量聚集，再产生非物理的力**

当前 `_collide_phase` 的法向与压缩系数为：

```
n = grad(phi) / (|grad(phi)| + 1e-14)
compression = 4*phi*(1-phi)/W
```

这里 `1e-14` 只防除零，几乎不能抑制 f32 量级的梯度噪声。纯水中的小幅欠相也会得到接近单位长度的法向；压缩项随即把它作为小界面处理，形成局部斑点，使本应被扩散消除的误差长期滞留。

支持这一判断的独立证据：

- 无流动、无受力、周期边界的纯相试验中，均匀 φ=1 保持不变；预置幅度 10⁻⁵ 的小凹点后，原压缩通量将它聚集并长期保留。关闭压缩项后凹点基本扩散消失。该试验只证明“聚集和保留”，没有把 10⁻⁵ 自行放大到实际算例的 5%。
- 完整算例逐阶段记录显示，底部最初的亚单位偏差约在第 95 步出现；同时存在 φ>1 的微小越界。`_bound_water_phase` 把超出 1 的部分截掉，合法的 φ<1 部分保留。前 4096 步，统计区域内累计裁去的相量为 0.644 cell-equivalent，最终区域欠相量为 0.299；碰撞相量漂移累计为 +0.116。区域边界存在相量通量，这些数值不能直接当作全域质量损失，但明确显示了裁剪对误差的不对称处理。
- 把相场零阶碰撞矩直接设为 φ，仅在 0.1 s 将最低 φ 从 0.98037 改善到 0.98817，污染仍明显。因此不只是某一项求和舍入误差。
- A 只改变法向的微小梯度处理，在压力振荡仍存在且幅值更大的条件下，1.07 s 的最大欠相仍从 5.144% 降到 0.107%。这直接支持法向/压缩通量是斑点维持和集中的关键机制。

压力模型允许有限的数值散度，而守恒相场输运包含 `div(phi*u)`；因此即便 φ≈1，非零 `div(u)` 也能向纯相输运注入误差。有限精度、输运离散、越界裁剪共同提供误差来源。本次尚未把最初种子中各项贡献完全分离，不将其全部归咎于舍入误差或单个节点重建。

斑点出现后，`rho = rho_air + (rho_water-rho_air)*phi` 使它成为局部低密度区，并生成 φ 梯度。在底部水温几乎严格为 90 ℃ 时，原算例的毛细加速度 RMS 约 0.207 m/s²、密度重力残差约 0.0515 m/s²，而热浮力残差只有约 10⁻⁸ m/s²。因此这里的竖向伪流不能用底部热对流解释。静水参考拆分会正确地响应这些错误密度；改写静水压力本身不能消除相场污染。

CAC-LBM 的体相非物理相与法向误差已有相应研究，Sato 与 Koshimura 用过滤改善法向并抑制体相污染。本次 A 是简单正则化对照，没有声称复现论文的完整过滤算法。[Sato & Koshimura, 2023](https://doi.org/10.1016/j.ijmultiphaseflow.2023.104554)

**2. 快速抖动：水柱内低耗散的数值声学驻波**

51.2 ms 加密采样窗中，主要峰约为 240–250 Hz 和 730 Hz。零填充插值得到约 243 Hz、731 Hz；原始频率分辨率约 19.5 Hz，插值不增加独立频率分辨率。

从当前压力平衡态和宏观压力恢复式线性化得到，均匀静止水中的数值声速为

```
c_num ≈ sqrt(0.6) * dx/dt ≈ 30.98 m/s
```

这里不能套用质量型 LBM 的 `dx/(sqrt(3)*dt)`。对于约 31.8 mm 的水柱，刚性底面、近似压力释放水面的四分之一波长模态给出 `f1≈c_num/(4H)≈244 Hz`，下一奇数模态约为 `3*f1`。

测量的压力竖向形状与 `cos(k*(y-y_bottom))` 的拟合 R² 分别为 0.999996、0.999965，同一点的压力与竖向速度约相差 90°。此前逐步数据中，`∂t(uy)` 与 `-∂y(p_dyn)/rho` 的相关系数为 0.999857。这些证据共同确认声学驻波性质，不是两格交替的棋盘模态。

激发与维持方面的控制试验：

- 从初始状态固定冰块并关闭热更新，到 0.1 s 底部 φ 仍为 1，速度 RMS 约 1.55×10⁻⁷ m/s。纯静水和静止底壁不是主要激发源。
- 从 1.07 s 同一状态关闭热更新，前 51.2 ms 的压力波动 RMS 为 134.65 Pa，原算例为 134.97 Pa，几乎相同。
- 在同一状态固定冰块、关闭热更新后，波动仍会自由演化；再冻结相场，也得到几乎相同的波动。这说明已经形成的声波无需持续的相场变化或热更新即可存在。
- 固定冰块会引入停止运动的瞬态，因此没有把“停止后仍有声波”当作排除运动边界激发的证据。初始静止对照与这些重启试验共同支持：落冰/运动边界过程是激发端，底部主要提供反射，当前碰撞耗散不足以迅速消除长波。

`_refill_changed_nodes` 对新暴露流体只填平衡分布、丢弃非平衡部分，是一个值得继续核查的压力脉冲来源。但本次没有在相同规定运动轨迹下单独替换 refill，不能宣称它已被证明是主要激发源。运动锐界面不满足几何守恒时可产生伪压力振荡，是已有研究支持的后续检查方向。[Chen, Yu & Hou, 2013](https://journals.aps.org/pre/abstract/10.1103/PhysRevE.87.053306)

![声学频谱、空间模态和同状态重启对照](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/outputs/bottom_root_cause_20260921/acoustic_evidence.png)

原输出每 0.01 s 一帧，无法解析上述频率，会产生混叠，强化视觉上的跳变感；加密数据确认振荡实际存在，所以仅提高输出频率不构成数值修复。

**3. 可选方案与当前建议**

**A：优先处理相场法向/压缩通量。** 本次有效的最小候选为：

```
n = grad(phi) / sqrt(|grad(phi)|² + epsilon_n²)
epsilon_n = 1e-3   # 本次网格下的格子梯度单位
```

这使非常弱的体相梯度不再得到单位压缩方向，在真正界面的较大梯度处接近原式。它不改变物理黏度、W 或 mobility，也不直接把接近 1 的 φ 强制设成 1。更完整的选择是用过滤后的相场计算法向，并配合保守、有界、保持纯相的通量处理，减少事后硬裁剪的质量偏置。

静止平面界面单独验证中，10%–90% 厚度为原式 5.653526 格、正则化 5.653531 格；8000 步质量相对变化分别为 −1.63×10⁻⁵、+8.25×10⁻⁵。这个结果仅覆盖平面静态界面，不代表曲率、接触角或小液滴都已验证。epsilon 还需要按界面厚度、网格和精度确定，不是通用常数。

**B：在压力型 CM-MRT 中联合调整压力相关矩，增加声学耗散。** 本次使用

```
s_trace = s_22 = 0.25       # 当前均为 1
s_20-02 = s_11 = 1/(0.5+3*nu_LU)   # 物理剪切黏度不变
s_00 = s_10 = s_01 = s_21 = s_12 = 1
K* = K - s*(K-Keq) + (1-s/2)*S
```

关键是压力兼容性。在 `u=0`、无源的线性极限，用原始矩表示宏观动态压力，有

```
p_dyn = (3/5) * (M20 + M02 - M22)
```

所以不能直接照搬标准质量型 CM 的“只调 trace”。独立傅里叶放大矩阵分析显示：只把 trace 从 1 改到 0.25，数值声速从 30.98 改到 32.30 m/s，长波声学衰减系数反而从 0.01668 降到 0.002694 LU；trace 与 22 同时设为 0.25，声速保持约 30.98 m/s，衰减系数升至 0.11668 LU，约原来的 7 倍。剪切模态黏度仍约为 3.142×10⁻⁵ LU。

这个线性结论不是对全部非线性两相工况的证明，但有同状态重启支持：从原来 1.07 s 的斑点、压力、速度和冰体状态出发，只用 B 演化 0.1024 s，后半窗的压力波动 RMS 从对照 136.21 降到 96.66 Pa，速度向量波动 RMS 从 3.222 降到 1.305 mm/s。

**B 不改变物理剪切黏度，但确实增加了数值体积/声学耗散。** 应把它作为独立可选参数说明，而不是称为“所有黏度都不变”。利用体积与剪切耗散分离抑制人工可压缩压力振荡，也有相应理论与数值研究；这里的联合松弛选择是针对本代码的压力矩关系推导的候选，不能直接归为论文给出的两相配方。[Qi et al., JFM 2025](https://doi.org/10.1017/jfm.2024.1206)

建议先将 A 与 B 作为两个独立开关验证，再考虑共同启用。仅 B 的完整试验虽将声波显著压低，固定斑点和最大伪速度仍然明显；仅 A 也没有消除声波。A+B 在本算例中将底部最大速度降低约 91%，压力波动 RMS 降低约 89%，最大体相欠缺降低约 99.9%。

若严格限制“只改动量 collision”，可采用 B 缓解快速抖动；消除固定相场斑点还需要 A 涉及的相场压缩处理。正式实现应保留 RM-MRT 的既有行为，将新的声学松弛只作为 CM-MRT 的可选设置。

**C：进一步减少激发源。** 在相同规定冰体轨迹下对比一致的非平衡 refill、切割单元体积/扫掠通量和边界压力约束；必要时做保持物理参数的网格/时间步收敛分析。这是后续改进方向，本次未把它计入已经验证有效的方案。当前容器底部是实体壁，不建议为了消波直接改成吸收边界。

**验证范围与复现**

候选 B 已通过独立矩阵碰撞/完整源项、运动压力平衡态不动点、剪切波黏度三个检查；A 通过上面的纯相小扰动与平面界面检查；四种完整对照均跑到 1.07 s 并继续采集 51.2 ms。它们仍是诊断候选，尚未完成静滴 Laplace 压差、平移液滴、接触角、移动边界力精度以及更长时间/网格收敛验证。冰体轨迹和融化量也有变化，不能只凭速度更小就认定全部物理预测更准确。

完整试验中，相较原算例，A+B 在 1.07 s 的冰体 x 位置变化约 −0.386 mm、y 位置约 −0.101 mm，冰质量约 −0.42%，流体格内相量约 +0.49%。这些差异可能同时含有伪流消除和数值耗散对解的影响，需要上述精度检查辨别。

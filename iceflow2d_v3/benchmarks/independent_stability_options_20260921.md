# W=5 四冰块：三项修改的独立实现与验证

本轮把三项候选实现为独立选项，保留原默认算法。**只有质量通量修正单独运行完成了
5 s；其液相体积漂移仍为 +10.0677%，不能据此认定守恒或精度问题已经解决。**
正则化动量与非平衡回填均未单独解决完整算例的失稳。

## 设置与完整算例结果

所有主对照从初始状态重新运行，每个候选只启用一项修改。域宽 15 cm、高 5 cm，
450×150，液面 2.5 cm，四块 1 cm 方冰的中心横坐标为 3、6、9、12 cm，纵坐标
4 cm，静止释放。保持 W=5、原有限差分法向、相场预热 2000 步，密度比 800，
真实分子黏度，水/冰/空气初温 90/0/20 °C，原热与刚体耦合，表面张力为零。

`reference_velocity=4 m/s`，`dx=1/3000 m`，`dt=1/120000 s`。
保留用户设置的全域 L1 速度终止阈值 16，逐步执行稳定性检查。
该阈值只控制报错时机，没有给任何候选速度限幅。

| 独立设置 | 最后步号 | 最后物理时间 | 结果 |
|---|---:|---:|---|
| 原默认 CM-MRT | 12,324 | 0.102700 s | 气相失稳；与修改前的失败位置和速度一致 |
| `momentum_collision_model="cm_hrr"` | 11,963 | 0.0996917 s | 气相失稳 |
| `phase_momentum_coupling="consistent_flux"` | 600,000 | **5.000000 s** | 全程完成，仍有体积和输运误差 |
| `exposed_node_refill="non_equilibrium"` | 11,839 | 0.0986583 s | 气相失稳 |

第二项完成运行的详细指标：

- 采样间隔 600 步，即 0.005 s；采样全域最大 `|ux|+|uy|` 峰值 0.138902 LU。
  这是采样峰值，不是每一步的精确峰值；非有限值和速度终止检查仍每一步执行。
- 5 s 时全域最大 L1 速度 0.00568437 LU，水相 `phi>0.5` 最大值 0.00301047 LU。
- 采样温度范围为 20～90 °C（上界舍入误差小于 8e-12 °C），所有采样场有限。
- 四块冰最终质量均为零；首次采样到融尽的时间分别为 4.195、4.290、4.695、4.610 s。
- 有效流体格点的 `sum(phi)` 从 31968.09927 增至 35186.54676，即 **+10.067685%**。
  当前 v3 的几何回填本来就不约束全局水量，原有相场越界修复也没有改为守恒限幅。
  本轮没有把这些体积变化归因于单一环节，也没有进行全局归一化。
- 5 s 时 `min(phi)=0.00093623`；气相区 `phi<0.01` 的平均 phi 为 0.00112177。
  按现有密度插值，最小流体密度已经约 2.185 kg/m³，高于纯空气的 1.25 kg/m³。
  因而不能把“完成 5 s”解释为纯气相保持、质量守恒和物理准确性均通过。

## 方案一：压力相容的 HRR 候选

开关：`--momentum-collision-model cm_hrr`。
`--hrr-kinetic-blend` 取 `[0,1]`，本次全部采用默认 0。
0 表示从速度梯度重建偏应力，1 表示保留动力学偏应力；两端都采用本候选的独立
压力矩闭合，因此 **blend=1 不等同于原 cm_mrt**。

二阶非平衡偏应力按

```
Pi_neq + source_2/2 = -rho*tau/3 * (grad(u) + grad(u)^T)
tau = 0.5 + 3*nu_LU
```

进行混合重建，第三阶非平衡中心矩消除后由二阶应力递归给出原始三阶矩。
第四阶采用独立的原始压力矩 `P = raw_22 - raw_20 - raw_02` 闭合；P 和二阶迹
使用指定声学松弛率及匹配的 `(1-s/2)` 源项系数。这样没有把质量型 Maxwellian
的零阶矩关系套入 `sum(g_eq)=0` 的压力分布。

梯度只读取碰撞前单独缓存的物理速度，避免在一个 GPU kernel 中读取邻格正在被
更新的加速度。固体边界使用 cut-link 距离和壁面速度构造梯度。

独立 Fourier 符号包含碰撞、空间梯度、流送及压力恢复；随后用真实生产内核验证。
测试为 64×64 周期均匀气相，实际空气黏度，波数 `(-13*pi/32,-13*pi/32)`：

| 模型 | 背景速度模长 LU | 预测每步放大率 | 生产实测放大率 |
|---|---:|---:|---:|
| 原 CM-MRT | 0.05 | 0.99638009 | 0.99638497 |
| 原 CM-MRT | 0.20 | 1.01886844 | 1.01887606 |
| HRR | 0.05 | 0.86115408 | 0.86119760 |
| HRR | 0.20 | 0.89878450 | 0.89894009 |

这说明本候选抑制了已定位的短波模态，**不说明所有波数或两相耦合都稳定**。
实际四冰块运行仍失败。

此外，64 格波长剪切波试验指定 `nu_LU=0.001`，原 CM-MRT 实测 0.001000531，
HRR 实测 **0.001397069（+39.7%）**。这是有限波长截断耗散；独立 Fourier 符号的
长波极限测试仍恢复指定分子黏度，但本候选在当前分辨率上的精度不能视为合格。
保留它用于比较和后续改进，不推荐作为本算例的单独修复。

实现方向参考 [Wissocq 等的正则化 LBM 线性稳定性研究](https://arxiv.org/abs/2006.07353)。
本项目的压力矩闭合是针对现有分布函数实现的候选，不能把文献结果直接当成本实现的验证。

## 方案二：完整质量通量修正

开关：`--phase-momentum-coupling consistent_flux`。

从本步实际相场碰撞前后的分布函数提取时间中心的非平流质量通量：

```
J_rho = (rho_water-rho_air) * [sum_q c_q*(h_q+h_q_post)/2 - phi*u]
```

对于当前相场碰撞，其连续极限为
`-(rho_water-rho_air)*M*(grad(phi)-4*phi*(1-phi)*n/W)`。
没有另选一套法向、mobility 或界面厚度来构造这个修正。

动量采用完整的 `F_c = -div(u tensor J_rho)`。共享面的质量通量和速度采用两侧
平均，同一面的贡献在两个格点上符号相反；固体和墙面不传输该非平流质量通量。
它包含 `-u*div(J_rho)` 和 `-(J_rho dot grad)u` 两部分。

采用力形式后，通过原有碰撞源项投影和半步力速度进入动量及压力恢复，没有再在
平衡态重复加入同一通量。基本依据见
[Zhan 等的一致质量与动量输运推导](https://arxiv.org/html/2111.00847v1)，尤其式 (15)、
(16c) 和附录 A；本实现没有声称逐式复刻该论文的另一套完整 MRT 模型。

该开关使用显式分裂：相场先按当前已恢复的物理速度碰撞，提取其通量，再更新动量；
原默认开关关闭时仍保持原先的调用顺序。这种从动力学通量矩到中心面通量的离散
仍有截断误差，**不是对逐条 streaming 链路的严格质量—动量一致性证明**。

针对性检查：

- 在周期、变速度的制造场中，完整通量力与独立面通量差分相符，全域合力为舍入误差。
  特意使用 `div(J)=0` 但 `J dot grad(u) != 0` 的场，排除了只实现标量补偿项的错误。
- 两相密度相等时质量通量修正严格为零。
- 时序消融：保留同样的相场提前碰撞时序，但将通量力置零，四冰块在
  **0.0989333 s** 失稳。因此该成功运行不能仅归因于改变调用顺序。

32×128 周期平直水层、W=5、密度比 800、匀速 0.01 LU，预热后运行 12000 步：

| 设置 | 最终最大速度保持误差 LU | 相对于初始速度 |
|---|---:|---:|
| 原算法（前一轮记录） | 0.004987617 | 49.876% |
| 仅 HRR | 0.004993338 | 49.933% |
| 仅通量修正 | 0.004987077 | 49.871% |

均匀平移保持误差并未明显改善，之前提出的低于 1% 的目标没有达到。
因此本选项的已验证收益是本次完整算例运行稳定性，精度仍有明确限制。

## 方案三：非平衡应力回填

开关：`--exposed-node-refill non_equilibrium`。

新暴露格点仍沿用原来外推的 phi、压力和速度；另外从最近一圈持续为流体的邻格
外推密度归一化的非平衡应力，再乘目标密度。所有供体都必须在更新前后保持为流体，
不读取本次 kernel 中正在被回填的节点。

将该应力重建为分布函数时保持零阶和一阶增量为零，原始四阶矩取二阶迹，使
`sum(q!=0, delta_g)=0`。因此附加应力不会改变目标动量或其压力恢复值；三阶矩
从应力递归重建。几何和相场体积重建规则没有改变。

单节点制造应力检查通过：应力被恢复，而指定速度、压力和零阶矩不变。
相同预设轨迹的额外对照使用 64×96 域，8×8 方冰由 `(32,54)` 以 `(0,-0.003)` LU
平移 4000 步，终点 `(32,42)`；两种回填的最终几何掩码完全一致，没有热更新、
重力或由不同水动力反过来改变轨迹的影响。

| 指标 | 平衡态回填 | 非平衡应力回填 |
|---|---:|---:|
| 最终最大 L1 速度 LU | 0.0206231 | 0.0205950 |
| 采样最大绝对压力峰值 | 0.000480753 | 0.000480753 |
| 最终压力 RMS | 7.46256e-6 | 7.51001e-6 |
| 液相体积相对变化 | +0.146816% | +0.146803% |

该对照没有显示明显的压力峰值改善；完整四冰块也未通过。
本轮不把原始失稳唯一归因于平衡态回填。

## 测试、默认行为与复现

新配置默认值：

```python
momentum_collision_model = "cm_mrt"
hrr_kinetic_blend = 0.0                 # 仅在 cm_hrr 中生效
phase_momentum_coupling = "legacy"
exposed_node_refill = "equilibrium"
```

独立开关测试确认：选择任意一项时，其他配置和物理参数保持不变。额外做了三项
同时启用的四步接口冒烟检查，但**没有把组合运行作为三项独立验证结果**。

新增 9 项配置/算子测试分别运行通过；既有配置和示例测试 16 项通过；动量、相场、
多冰块回归共 27 项中 26 项通过，1 项失败：
`test_four_block_default_survives_water_entry` 要求默认配置通过 0.35 s。
保留原 W=5 默认意味着这项既有失败仍存在。将修改前生产源文件复制到隔离临时目录
后重跑同一测试，也得到完全相同的 `0.3562948405742645 >= 0.25` 失败值。
本轮没有调高该测试断言或更换其默认配置来隐藏失败。

三项开关还分别通过真实四冰块命令行的三步运行，输出 `metadata.json` 中的选项
与命令行一致。修改文件通过 Ruff 检查和格式检查，`git diff --check` 通过。

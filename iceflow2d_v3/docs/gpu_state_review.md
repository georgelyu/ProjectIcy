# v3 GPU 状态

融水注入、回退池、质量/能量残差、全局开口归约、水量求根以及融化动量补偿的字段与内核均已删除。

保留的主要状态：

- 两组 D2Q9 populations 和各自流送缓冲，以及相场、速度、加速度和压力。
- 冰体位姿、速度、质量、质心、惯量、锐界掩码、覆盖率和接触支撑。
- 材料冰质量、材料显热及一张热增量数组。
- 世界水体积、水显热、面通量及一张局部温度重构缓冲。

局部重映射先读取旧数组构造目标显热，再统一写入新水体积和显热，避免并行读写竞争。
温度、SDF、墙掩码、半力速度及采样显示场仍按需派生。
刚体质量矩和 cut-link 载荷使用 f64；热稳定性仍按四个面的总向外速度选择 CFL 子步。

详见 [当前模型及运行方式](../README.md)。旧版性能数字不代表当前版本。

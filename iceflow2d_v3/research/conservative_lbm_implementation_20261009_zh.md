# 双 LBM 冰水质量守恒实现与性能

日期：2026 年 10 月 9 日。实现保留压力型动量 D2Q9 MRT LBM、相场 D2Q9 中心矩 LBM及原有 cut-link 锐界边界。水量由相场 populations 的零阶矩给出；材料冰的实际质量损失转移给液水。运行时不计算全域水质量总和，质量改变的操作通过局部事件收支和有界转移闭合。

## 守恒口径

二维质量是单位面外厚度对应的 kg/m，体积对应 m²。密度固定、没有水出流和蒸发时，验收关系为

\[
M_i(t)+\rho_w V_w(t)=M_i(0)+\rho_w V_w(0),\qquad
V_w(t)-V_w(0)=\frac{M_i(0)-M_i(t)}{\rho_w}.
\]

采用冰密度 917、水密度 1000 kg/m³时，100 cm³冰生成91.7 cm³水。冰水总体积减少8.3 cm³；现有水池的液水体积增加91.7 cm³。

流体节点的水体积为 `dx² × sum(h_q)`，墙和锐界固体节点的 populations 清零。相场 populations 与零阶矩使用 f64，动量及相场高阶碰撞算术保留 f32。每次碰撞通过静止 population 关闭实际零阶矩，不依赖全局水量投影。

## 算子与事件预算

普通内部链路交换成对抵消。供体限制只避免透支水量，允许饱和纯水格点的循环通量；显热对流使用同一份实际质量通量。因此，纯水区的水量不变仍能发生显热对流。

以下操作单独记录实际改变量：移动冰壁对相场反弹 populations 的修正、新覆盖节点排除的水量、新暴露节点回填的水量，以及越界修复前后零阶矩的差。压力 populations 不作为水质量统计。每个事件的残量为“实际移除量减去实际生成量”；正残量需要放回水，负残量需要从已有水中扣回。

冰材料相变保留实际 `old_mass - new_mass`，包括部分融化。材料到世界网格采用非负的多边形相交权重，供体分配闭合；锐界尚未露出流体节点时，将融水放入最近可用流体节点，等距离受体共同分配，避免方向偏置。融水以熔点显热零点进入，材料融尽后的剩余显热也转移给水。守恒模式不无记录清零材料残冰。

源量完成后，先在同一连通水体内按各事件的收支比例结清正负事件，并按供体事件的平均比显热分配能量，再把剩余净变化均匀分配到相关自由液面。这避免并行受体列表的顺序决定冷融水与热水的配对位置。均匀分配依据事件量、可接收/供给格点的数量及最小容量，不求水质量总和；均温时转移同时携带相同的比显热。极端容量不足时按受体逐笔预留，不能把无法分配的水丢弃。若封闭区域没有足够空间，报告容量不足而非丢弃质量；开边界出入流尚需另设边界质量预算。

液相连通性及一层可接收邻域用于隔离无关水滴。非法负值的弥散界面尾部没有本地液体供体时，寻找最近的可达液体供体，路径不能跨墙或封闭冰体。拓扑不变时复用连通标签。

冰水密度差的法向边界偏移采用

\[
\boldsymbol u_w\cdot\boldsymbol n
=\boldsymbol u_i\cdot\boldsymbol n
+j\left(\frac1{\rho_w}-\frac1{\rho_i}\right),
\]

其中法向从冰指向水，融化质量通量由实际材料质量损失映射到原世界位置，使用重定向之前的空间分布，界面测度在格点尺度正则化。切向沿用原有边界处理。

容器约束同时覆盖有质量的材料方格，包括低于锐界阈值的残冰；不能让阈值掩码忽略的材料穿过墙后继续丢失或融化。冰块之间的接触仍沿用原有锐界格点处理。

## 时间步与热模块

流动阶段完成碰撞、供体预算、流送、宏观恢复、压力恢复和有界事件结算；运动阶段对启闭格点进行结算；每个热子步提交实际融冰量及剩余显热后再结算。热模块读取相场零阶矩，不独立输运另一份水量。FV 与 D2Q5 的导热选择保持有效。

质量包含全部相场尾部。温度和物性的计算仍区分数值上可解析的湿区域，避免把接近零热容量处的浮点残差当作温度；这个判据不删除质量。`fields.npz` 增加 `water_volume_cells`、`fluid_capacity` 和 `water_sensible_energy_j_m`，便于独立质量及热量核查。

## 验证与性能复现

守恒测试覆盖平移/旋转、密度比0.5/0.917/1、部分和完全融化、空气中融水生成、剩余显热、FV/D2Q5、纯水循环显热对流、等温几何转移，以及独立水滴隔离。流动验证包括静止液滴 Laplace 压差、水平冰块0.3 s入水及四冰块0.35 s入水。

性能测量在 RTX 5090、驱动570.211.01、Taichi1.7.4、conda `icy` 的Python3.10.20环境中进行。基准与新方法使用相同物理参数和 `consistent_flux`；计时不含初始化、文件输出和质量审计，逐批等待GPU完成后取五次中位数。旧版基准来自提交 `457ac81fa1b1f333c9164d281536b3dcc03f7232` 的独立源码快照。每步时间含Python调度及事件标志同步，不是单个GPU kernel的时间。

原始结果保存在 `iceflow2d_v3/outputs/conservative_lbm_20261009/`。单冰块采用100×200网格、预推进512步；四冰块采用450×150网格、预推进18000步，即0.15 s，随后每次计时512步。四冰块长时质量审计已完成600000步，即5 s；审计求和在计时区间外完成。长时审计与其他GPU检查并行时，其计时数据不作为性能结果。

```bash

conda run -n icy --no-capture-output python -m iceflow2d_v3.benchmarks.benchmark_conservative_lbm \

conda run -n icy --no-capture-output python -m iceflow2d_v3.benchmarks.benchmark_conservative_lbm \
```

## 最终验证结果

- 守恒专项11项全部通过，包括输出字段核查、密度比0.5/0.917/1、部分及完全融化、空气中融水、显热、FV/D2Q5、运动重映射、容器约束和独立水滴。
- 配置、CLI、输出和进度相关29项检查通过；静止液滴16000步的残余速度与Laplace压差检查、水平冰块0.3 s入水回归通过。
- 四冰块450×150网格自然融化推进600000步（5 s），143个审计样本中最大冰水总质量相对误差为 **2.9532×10⁻¹⁴**，相场和动量 populations保持有限。
- 初始水量31968.0格子面积，初始冰质量折算3301.2格子面积的水；最终水量35269.199999998986，残冰水当量2.18×10⁻¹²。自然融化未删除这个微小残量；专项的完全相变测试另验证冰质量严格为0。

审计中的格子面积对应 `dx²`，450×150算例的 `dx=1/3000 m`。初始冰面积0.0004 m²、质量0.3668 kg/m，新增水面积0.0003668 m²；密度差对应的体积收缩由质量换算给出。

## 性能开销来源

新增成本来自 f64 相场 populations 的访存、受供体预算限制的链路计算、同通量显热对流、事件与界面容量预算，以及有事件时的连通性和分配。连通标签在拓扑不变时复用；相反符号的事件以一次比例结算完成，避免每个供体扫描全部欠款受体。主要正常路径是 O(N) 格点处理；异常容量不足的逐受体预留、最近格点搜索仍可能更贵。因此“无需全域水质量求和”不等于零开销，也不能保证任何几何下都是 O(1) 的局部修补。

性能表统计 Taichi 字段的有效载荷，不包括GPU运行时、编译缓存和分配器预留；不能把这个值当作 `nvidia-smi` 显存占用。相场 storage使用双精度，但动量仍为单精度。结果会随GPU双精度吞吐、界面规模、热更新间隔和接触次数变化。

## 精度与模型范围

本实现关闭的是冰和液水质量。材料冰体积 `M_i/rho_i` 与二值固体格点数不要求逐步相等；原有锐界格点、接触和不可见残冰运动仍有网格尺度误差。总水量正确不能独立证明界面位置、载荷和融化时间已经收敛，这些仍需网格、界面宽度和时间步的收敛检查。

气相密度仍使用现有模型的常数；密闭容器的气体压缩、空腔压力响应、蒸发和新冰形成不在这一质量守恒模式的保证范围。质量和热量验证采用明确的浮点容差，不宣称逐位严格相等。

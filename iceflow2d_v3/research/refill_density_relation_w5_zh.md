# W=5 回填平均 phi 与冰水密度比的关系

日期：2026-09-22。复核已有 600,000 步水量账目及生产代码；本次没有重跑不同密度的完整下落算例，没有修改生产求解器。

**结论：存在密度影响浮力、浸没位置和融化过程的间接联系，但当前算法没有保证“回填平均 phi = 冰水密度比”。0.918716 与 0.917 的数值接近，不能单凭这一次结果认定由浮力决定，也不能据此宣称相变质量守恒。**

## 两个比值统计的对象不同

本次所说的平均值是：

```text
回填平均 phi = 融化刷新中新增水量 / 融化刷新暴露格点的累计次数
              = 2800.245886188 / 3048
              = 0.918715841925
```

它只统计“旧固体 → 新流体”发生在融化几何刷新中的节点。另有 552 个净释放格点计入运动刷新；因此分母既不是初始的 3600 格，也不是材料冰质量损失。连续模型中，与之相近的量是按界面局部退缩速度加权的边界环境相分数，而不是冰体积中的水下比例。

`_extrapolate_exposed_fluid` 读取持续为流体的最近一圈邻居，将邻居 phi 限定到 [0,1] 后取平均。`_refill_changed_nodes` 将它写入新节点。两个过程均没有使用 rho_ice/rho_water 来指定回填值。同一位置、同一邻域 phi 和同一次几何退缩下，仅改变密度参数不会直接改变这条回填公式。

代码：[邻域外推与回填](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/simulator.py:2199)。

## 浮力提供的是间接联系

对静止自由漂浮、忽略空气浮力与表面张力的均匀冰块，重力与浮力平衡给出：

```text
rho_i * V_ice * g = rho_w * V_submerged * g
V_submerged / V_ice = rho_i / rho_w = 0.917
```

这是冰块的水下体积占比。来源：[OpenStax《University Physics Volume 1》14.4，Archimedes’ Principle and Buoyancy](https://openstax.org/books/university-physics-volume-1/pages/14-4-archimedes-principle-and-buoyancy)。若同时保留空气浮力，理想平衡比例为 `(917-1.25)/(1000-1.25)=0.916896120150`。

生产代码中的冰密度参与冰的质量与重力；边界压力和动量交换提供流体作用力。二者影响冰块位置，进而影响邻域 phi、接触热水的部位以及随后发生融化的节点。密度也影响单位几何体积的材料质量和潜热需求。这些都是密度间接影响回填统计的途径。

代码：[刚体质量初始化](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/simulator.py:1321)、[重力与流体冲量积分](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/simulator.py:3165)、[冰壁压力作用](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/simulator.py:3598)。

但要把水下体积比例替换成融化节点的平均 phi，还需要额外假设：发生融化的区域以近似相同的权重代表整个冰体积，并且回填准确代表当地水气占比。实际算例有入水、回弹、不同部位的换热、W=5 弥散界面、二值格点开闭以及运动/融化的分步处理，不能直接作这个替换。

一个纯几何反例可以说明差别。设二维方冰边长 L，水下高度为 rL，周围为锐界水气；规定四条边以相同速度退缩，暂时保持位姿不变。忽略角部二阶小量，总退缩面积正比于 4L，水侧退缩面积正比于底边 L 加两条侧边的水下部分 2rL，因此这次退缩的水侧比例为 `(1+2r)/4`。即使 r=0.917，该比例也是 0.7085。这个反例是规定的几何退缩，不是本项目热模型的模拟结果；它说明“浮力平衡”本身推不出“融化回填平均 phi 等于密度比”。

## 已有数据能够证实什么

同一次 W=5 运行中，冰水密度比始终为 0.917，但按时间段重新求平均得到：

| 时间段 / s | 融化暴露格点数 | 该段回填平均 phi |
|---|---:|---:|
| 0–0.1 | 19 | 0.631843 |
| 0.1–0.3 | 424 | 0.929132 |
| 0.3–0.5 | 470 | 0.951698 |
| 0.5–1 | 729 | 0.928301 |
| 1–2 | 767 | 0.909594 |
| 2–3 | 410 | 0.873122 |
| 3–4 | 229 | 0.937205 |
| 4–5 | 0 | 无融化开格，不定义该段均值 |
| 全程 | 3048 | 0.918716 |

全程平均是按各段暴露格点数加权的结果。这说明回填并没有在每段自动维持密度比；但时间段有波动本身也不能排除密度对全程平均的间接影响。

先前的固定 8×8 冰块、纯水环境、规定完全融化对照还给出了更直接的结果：在水密度为 1000 kg/m³、冰密度分别为 500、917、1000 kg/m³ 时，原始回填都增加 64 格，平均 phi 都是 1。这里读取的是校正前的 `original_increment_cells`，不是原型守恒校正之后的数据。见[对照原始数据](/home/georgelyu/Repos/ProjectIcy/iceflow2d_v3/outputs/simple_melt_volume/results.json)。

如果考察整个下落算例真正的净增水量，则：

```text
净增液水 / 初始几何冰体积 = 3218.447499413 / 3600 = 0.894013194281
```

这个量包含运动、移动壁面、限幅和舍入，才对应“初始每一格冰最终净增加多少水”。它与只统计融化开格的 0.918716 不是同一口径。

因此可以确认“没有密度比回填或守恒恒等式”，并指出浮力可能产生关联；目前没有完整算例的密度对照和逐时刻浸没体积数据，不能把 0.001716 的接近程度定量归因于浮力。需要区分已有算子证据、理想浮力推导和尚未验证的因果判断。

# 微小残冰的位姿与相变动量

旧独立 v2 长跑在 9.39553125 s 首次发生真实顶点位移超限。完整批次随后出现容量失闭和非有限值，最后接受时间为 9.39 s。该失败及检查点保留在 `outputs/contact_parallel_100`、`outputs/audit_full_terminal`。以下修正改变数值离散，不能套用接触极值搜索的等价迁移凭证；最终场景须从初始条件重跑。

## 位姿时间层

设固定材料参考点为 O，当前质心为 C=O+s/M，世界线、角动量为 P、L，质心惯量为 I。刚体平移/转动子步内形状和动量不变。格子时间步为 1 时：

```
omega = (L - C × P) / I
C_new = C + P / M
R_delta = rotation(omega)
O_new = C_new - R_delta (s/M)
```

原来直接 Euler 推进 O，会让实际质心产生二阶于角位移、正比于参考点偏心距离的虚假位移。惯量趋近零时，这个误差经世界角动量恢复会放大。原流程还在更新姿态后、刷新世界一阶矩前恢复速度，导致保存的速度与质量矩不在同一时间层。

现在按上式推进质心并重建 O，刷新世界一阶矩后再处理接触/恢复速度，并在最终栅格化后保持速度一致。补偿动量在 f64 中合成后参与小型刚体计算，库存仍以补偿 f32 保存。偏心微小残冰的 200 步无力自由运动测试检验解析质心轨迹和恒定自转；旧版本第一步便产生约 0.0136 格的质心偏差，新版本通过。

## 实际退缩区域的动量积分

对同一个材料单元，使用旧多边形减去已接受热量驱动的新多边形，得到被移除区域的质量 ΔM、一阶矩 Δs 和极惯量 ΔJ。设共同刚体速度为 v=(u_Ox,u_Oy,omega)，则该区域的材料动量是

```
P_removed = ΔM u_O + omega J90 Δs
L_removed_about_O = Δs × u_O + omega ΔJ
```

不能把整块将被移除的材料都放到旧边界上并乘一个瞬时速度：接近单元消失时，这会错误估计流出的转动惯量。各接触面的质量、热量和潜热仍来自原来那一份已接受交换；材料动量按同一单元内的质量权重分配。被移除区域自身的角动量通过现有局部连通力偶传给流体单元，单独的附加力矩字段保留其作用。

## 有限体积隐式闭合

令 G0、G1 分别为旧形状和剩余形状关于 O 的广义质量矩阵，G_removed=G0-G1。J_rel 为同一份接受质量及 Stefan 相对速度形成的广义冲量。选择同一个隐式速度 v1：

```
G0 v1 = p0 - J_rel
p1 = G1 v1
p_out = G_removed v1 + J_rel
p1 + p_out = p0
```

小型求解在旧质心坐标中进行，不对趋近零的剩余惯量求逆。完全融化时 G1=0，刚体动量自然变为零，原动量全部通过界面交换交给流体；没有按质量阈值删除冰或清空未转移的动量。固定刚体的对应冲量进入显式支承账本。

这个更新是针对相变子步的一阶隐式离散，不声称整个耦合二阶。它不修改接受的融化质量、潜热或数值空气体积源，也不改变白名单 D2Q9/SNIBB 公式。

面记录的 f32 舍入与几何积分求和会产生小量差异。`phase_momentum_roundoff_x/y` 和 `phase_angular_momentum_roundoff` 记录“面记录积分－刚体实际损失”；这些量不作为外力加入预算，也不用于全域补偿。另有独立测试直接积分流体单元收到的源和力偶，与刚体动量变化比较。
